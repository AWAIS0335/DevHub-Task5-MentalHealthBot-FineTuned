# Task 5: Mental Health Support Chatbot 🧠💙

This repository contains my solution for Task 5 of the AI/ML Engineering Internship at DevelopersHub Corporation.

**Objective:** Build a basic chatbot that provides supportive and empathetic responses using LLM fine-tuning.
**Dataset:** Empathetic Dialogues (Facebook AI) - Parquet version.
**Model Base:** DistilGPT2.
**Tools Used:** Hugging Face `transformers` and `datasets` libraries, Trainer API, PyTorch.
